# Riftbound

Owns official catalog ingestion and reference-card data, not rules execution
or the shared manual tabletop.

- Printed text, keywords, costs, and statistics are display/search metadata.
  Do not turn them into executable effects, legal actions, or automatic prompts.
- Use the official Card Gallery or authenticated Riot API and preserve source
  provenance. Community databases are not fallback sources.
- Keep Riot credentials server-side and out of logs, snapshots, and bundles.

Use focused package checks. Live-source checks are opt-in; authenticated API
checks need an explicitly supplied key.
