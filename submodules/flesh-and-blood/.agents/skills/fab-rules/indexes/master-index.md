# Flesh and Blood Rules Master Index

Canonical source: official Flesh and Blood Comprehensive Rules, scraped from
<https://rules.fabtcg.com/en/cr/> into
[`references/flesh-and-blood-comprehensive-rules/`](../references/flesh-and-blood-comprehensive-rules/).
Rules are cited as `Chapter.Section.Rule` (for example `7.5.2`). Open only the
minimal chapter files needed; the full official glossary lives in
[`references/flesh-and-blood-comprehensive-rules/glossary.md`](../references/flesh-and-blood-comprehensive-rules/glossary.md).

## Authority Before Rule Lookup

For a named card, token, or release mechanic, search
[`references/errata-bulletins.md`](../references/errata-bulletins.md) **before**
using this index. Errata has higher priority than the Comprehensive Rules and
all release notes. Then consult the current Comprehensive Rules through this
index; use [`references/release-notes.md`](../references/release-notes.md) only
for the relevant set-specific ruling that survives those higher authorities.
