# Official Flesh and Blood Release Notes

This is the complete official release-note index as published on 8 August 2026.
Each entry is a historical, set-specific ruling source. The publisher cautions
that release notes are rarely updated after their set releases, so they can be
superseded by later rules/policy changes and, in particular, by an errata
bulletin. Use these notes to explain a set mechanic or card interaction only
after checking `errata-bulletins.md`.

## Source and citation

- Official index: <https://fabtcg.com/rules-and-policy-center/release-notes/>
- Legacy official index (stable document URLs): <https://legacy.fabtcg.com/en/resources/rules-and-policy-center/release-notes/>
- Citation form: `Release Notes — <set>` plus the direct URL below.

## Local archive

The full source text is stored one release per file in
`official-updates/release-notes/`, with provenance and a source-content hash
in each file's front matter. Use this catalogue to select a set, then open
only its local file. Normalize it with:

```sh
node .agents/skills/fab-rules/scripts/format-official-updates.ts
```

Do not infer a general rule from a release note when the Comprehensive Rules
or an errata bulletin provides a contrary answer. Open the linked source for
the card-by-card notes; this index preserves every official release-note entry
without duplicating the publisher's long-form card text.

citation for card-specific behavior.
