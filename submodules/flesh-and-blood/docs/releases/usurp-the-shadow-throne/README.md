# Usurp the Shadow Throne preview branch

Pinned FAB Cube source: [1e693bf3b333](https://github.com/the-fab-cube/flesh-and-blood-cards/tree/1e693bf3b333bbc24835ba65d67e026fd50fd59a), checked September 3, 2026. This is a partial preview inventory, not a claim that the full set is revealed.

114 variants / 88 names; 34 variants in 22 families were absent from the baseline catalog. ## Run and review

From the simulator app, run `pnpm run dev --host 127.0.0.1 --port 5190`, then use the links below. Fixtures show a reproducible choice or result; reload to reset. Card-specific instructions and printed text appear in the scenario description. The opponent uses the pass-only bot; use Take over when you want to inspect or change its response.

Official IAR art from Legend Story `/media/cards/large/` is staged in the sibling assets repository (546 × 763 WebP, verified board crops). Catalog printings now emit first-party CDN URLs for 497 of 499 IAR printings. Remaining Cube gaps: IAR158 Runechant and Gate to i'Arathael (null source URL; those cards still have older-set art), and Rise to the Challenge (IAR050–052) which Cube has not given printing rows. Images appear in the simulator only after the assets PR publishes those hashes to R2.

## Final reveal and release gate

1. Scrape the latest FAB Cube set ref from the FAB workspace with `vp run scrape -- --ref usurp-the-shadow-throne`. Preserve the returned commit and raw snapshot.
2. Run `node docs/releases/usurp-the-shadow-throne/compare-source.mjs <new-scraper-snapshot.json>` to list added/removed variants and changed fields. Review changes even when names are unchanged.
3. Regenerate catalog and identities through the owning catalog tools using the approved asset manifest. Author every added card and revise behavior for any changed text/stats. Add/update its unit tests and visual fixture; update this pinned inventory only after review.
4. QA every row below; add new rows as cards appear. The presence of a fixture is not human QA sign-off.
5. Verify final official images, dimensions, aspect ratio and printing identity in the sibling assets repository. Keep missing or unapproved images unavailable; never substitute screenshots, upscale previews, or hand-patch generated catalog URLs.
6. Run FAB `vp run ci-check` and `vp run build`, simulator fixture tests, simulator type/build gates, and representative browser interactions. Review the full changed-path boundary before publishing.
7. Keep the branch unmerged until the complete set and final artwork are confirmed. Production deployment remains owned by reviewed CI/CD.
