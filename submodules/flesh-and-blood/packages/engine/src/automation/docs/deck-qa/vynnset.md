## Core interaction analysis

- At the real start-of-turn boundary Vynnset banishes one hand card and creates one Runechant only if the banish succeeds. Playing a Shadow non-attack action then offers a one-life payment; accepting makes only the next Runechant damage effect that turn unpreventable.
- Flail of Agony costs life, attacks once, and creates a Runechant only on hit. Vexing Quillhand/Grasp/Grimoires are distinct Runechant routes. Spellbound Creepers requires an attack or an attack-action defense earlier that turn, changes only the next non-attack action's timing, and has a bind-counter survival check at end phase.
- Face Purgatory requires equipment, an attack action, and a non-attack action to defend together in the same defend event. Reduce to Runechant's cost reduction reads current Runechant count. Dyadic/Grimoire/Ebon Fold cover Arcane Barrier, Spellvoid, and Blood Debt as separate replacement/end-phase paths.
