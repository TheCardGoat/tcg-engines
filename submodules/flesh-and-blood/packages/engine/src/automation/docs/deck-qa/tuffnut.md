## Core interaction analysis

- Tuffnut's instant pitches the deterministic top deck card; a 6+ power result makes the crowd cheer, and each cheer creates one Toughness. A non-6 result still moves to pitch but creates neither cheer nor token.
- Comeback Kicks converts a cheer into an action point only while behind every other hero. Gauntlets of Tyrannical Rex require a 6+ power card already in pitch. Rok requires an empty hand, and its physical damage cannot be prevented. Scabskin is a deterministic-RNG boundary, not permission to hard-code a favorable roll.
- Defense is part of this deck's identity: Good Natured Brutality checks empty hand as it defends; Dig In converts paid resources into Toughness; No Hero Stands Alone uses ambush and clash; Tough/Vigorous Smashup create different tokens; Scowling Flesh Bag intimidates on defend.
