## Core interaction analysis

- Gravy's instant requires an untapped hero and a controlled Gold. Drawing happens before the mandatory chosen discard; discarding a blue card establishes the same-turn graveyard permission. The permission applies only to cards with watery grave in the graveyard, while watery grave itself turns an arena-to-graveyard card face-down (CR 8.3.41).
- Compass grants go again only to the first watery-grave card played from the graveyard each turn. Gold-Baited Hook can create or steal Gold on the next Pirate hit and destroys itself at end phase if neither occurred. Dead Threads requires an ally to have entered the graveyard that turn.
- The defensive core is unusually rich: Blood in the Water can discard or destroy the deck top for +2 defense; Base of the Mountain adds banished hand actions as simultaneous defenders; Sawbones prevents damage; Quickdodge Flexors is activated in the Reaction Step and is destroyed in the end phase; Sunken Treasure can create Gold from a yellow graveyard card.
