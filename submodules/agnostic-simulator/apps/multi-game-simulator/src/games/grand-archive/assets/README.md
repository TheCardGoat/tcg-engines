# Board asset ownership

Finished board artwork is hosted at
`https://cdn.tcg.online/public/grand-archive/simulator/ui/board/v1/`.
The sibling TheCardGoat/assets repository owns the images and publication.

`themes/cambria/themes.ts` maps the published wide/compact assets to the
existing Avalon, Camelot, and Varuck presentation settings. Shared felt uses
the published Archive surface. No board images are bundled in this application.
