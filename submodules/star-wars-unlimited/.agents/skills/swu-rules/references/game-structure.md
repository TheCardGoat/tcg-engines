## Implementation Notes

- The action phase alternates active-player actions until both players pass
  consecutively.
- Taking initiative is an action that changes who has initiative and interacts
  with phase progression.
- Regroup readies cards, draws cards, and resources cards according to the
  official sequence.
- Base defeat is the primary two-player loss condition.
