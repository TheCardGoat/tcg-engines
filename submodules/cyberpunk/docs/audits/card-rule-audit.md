# Cyberpunk card rule audit

## Scope and method

- Reviewed all 152 canonical runtime card definitions and their English `rulesText`, including builder-authored abilities, Gear attachment, cost modifiers, and static rules. Each row gives a source-level verdict on the printed requirement and the encoded timing, target scope, condition, count, and cost. The linked focused test is a coverage location, not proof that every edge case passes.
- Rule source: `.agents/skills/cyberpunk-tcg-rules/references/comprehensive-rules.md`. Relevant rules: 4.2.1, 4.10.1–4.10.3, 5.7.4.1, 5.11.4.1–5.11.4.2, 10.6.1–10.6.2, 10.15.1, 10.16.1–10.16.3, 10.20.3–10.20.4, 10.31.1–10.31.2, 11.2.1–11.2.3, 11.6.1–11.6.6, 11.8.1–11.8.4, 11.19.1–11.19.2, 11.21.1, 11.25.1, 11.26.1–11.26.3.
