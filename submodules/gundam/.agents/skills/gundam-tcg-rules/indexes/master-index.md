# Gundam Rules Index

Source: `../references/comprehensive-rules.md`

Version: Gundam Card Game Comprehensive Rules 1.7.0, updated May 22, 2026.

## How To Use

1. Load `../references/glossary.md` first.
2. Pick the smallest matching section below.
3. Read that numbered section in `../references/comprehensive-rules.md`.
4. Cite rule numbers in the final ruling or implementation handoff.

## Sections

- 1. Game Overview: players, defeat, concession, card-text precedence, impossible actions, simultaneous choices, numeric rules.
- 2. Card Information: card number, name, type, color, traits, zone, AP, HP, Lv., cost, card text, link condition.
- 3. Card Types: Units, Pilots, Commands, Bases, Resources, Pilot effects on Commands.
- 4. Game Locations: deck, resource deck, resource area, battle area, shield area, removal area, hand, trash.
- 5. Essential Game Terminology: effects, players, active/rested, damage, HP recovery, play, deploy, pair, destroy, discard, remove, tokens, counters, "if/then", reduce.
- 6. Preparing to Play: deck, resource deck, tokens, setup, mulligan, EX Base, EX Resource.
- 7. Game Progression: Start, Draw, Resource, Main, End phases and main-phase actions.
- 8. Attacking and Battles: attack target legality, Block Step, Action Step, Damage Step, shield/base damage, battle end.
- 9. Action Steps: action timing and allowed effects.
- 10. Effect Activation and Resolution: effect types, conditions, activation steps, resolution, triggered effects.
- 11. Rules Management: defeat, destruction, battle area excess, shield area base excess.
- 12. Multiplayer Battle: Battle Royale, Team Battle, shared shield rules, teammate blocking.
- 13. Keyword Effects and Keywords: Support, Breach, Repair, Blocker, First Strike, High-Maneuver, Suppression, Development, Burst, Pilot, Deploy, Attack, When Paired, During Pair, When Linked, During Link.
