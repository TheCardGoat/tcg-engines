# Gundam Tournament Meta V1

The V1 classifier groups complete Main Deck evidence by the dominant game-owned
source title, then appends the deck's exact one- or two-color identity. The
40-card minimum is an evidence-quality floor for classification; it is not the
Gundam Deck construction rule. A legal Main Deck is exactly 50 cards under
Comprehensive Rules 6-1-1.

The classifier returns `unclassified` when catalog coverage, dominant share,
lead, distinct-card breadth, or color identity is insufficient. Color overlap
alone never assigns an archetype.

`GUNDAM_TOURNAMENT_META_METHODOLOGY_CANDIDATE_V1` is a parity candidate derived
from the competitor report's observed placement formula. It is not official,
is not endorsed by Bandai, and its sample floor and S-D cutoffs require
statistical-review approval before any production publication.
